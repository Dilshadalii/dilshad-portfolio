# Dilshad Ali — Portfolio

My personal data science portfolio website, showcasing my background, experience, and projects in machine learning, deep learning, and computer vision.

## Live Site
https://dilshad-portfolio.vercel.app/

## Tech Stack
- HTML, CSS, JavaScript (vanilla, no framework)
- EmailJS for the contact form
- Deployed on Vercel

## Running Locally
```bash
git clone https://github.com/Dilshadalii/dilshad-portfolio.git
cd dilshad-portfolio
python3 -m http.server 8000
```
Then open `http://localhost:8000` in your browser.
